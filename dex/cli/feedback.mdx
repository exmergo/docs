report a bug or suggest an improvement: the environment to paste and prefilled issue links (no connection, nothing sent)

```text
dex feedback [--command SUBCOMMAND]
```

**Options**

| Option | Description | Default |
| --- | --- | --- |
| `--command SUBCOMMAND` | the command that misbehaved, named in the bug report link |  |

Every command here also accepts the [global options](/dex/cli/overview#global-options).
