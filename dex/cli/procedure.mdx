print the agent procedure, or the block to paste into CLAUDE.md / AGENTS.md (no connection)

```text
dex procedure [--block] [--check FILE]
```

**Options**

| Option | Description | Default |
| --- | --- | --- |
| `--block` | also return data.block, ready to paste into CLAUDE.md or AGENTS.md |  |
| `--check FILE` | report whether FILE carries the current procedure (repeatable) |  |

Every command here also accepts the [global options](/dex/cli/overview#global-options).
