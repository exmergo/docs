## dex maintain coverage

Count each model's, source's, snapshot's and seed's own tests by kind, its downstream tests, incremental branch tests and asserted columns, each against a stated denominator; each test's last run status, each model's recorded mutation score (fresh or stale), the columns singular tests read, and what checks each declared fact. Free; reads the manifest, run results and .dex/ only. `--mutate` refreshes stale and missing scores in one batch, behind one cost handshake.

<Accordion title="Usage and options for dex maintain coverage">

```text
dex maintain coverage [--full] [--mutate] [--max-models N] [--target TARGET]
    [<object> ...]
```

**Arguments**

| Argument | Description | Default |
| --- | --- | --- |
| `[<object> ...]` | model, source.table, snapshot or seed names (default: all) |  |

**Options**

| Option | Description | Default |
| --- | --- | --- |
| `--full` | lift the caps on every listed section and name |  |
| `--mutate` | refresh stale and missing mutation scores |  |
| `--max-models N` | refresh at most N models (25, never more) |  |
| `--target TARGET` | dbt dev target `--mutate` runs against; prod-looking targets are refused |  |

</Accordion>

## dex maintain incidents

Fold test outcomes from Elementary's tables and dbt's run results into incidents: open, closed or no longer observed, each with its coverage and retention bound. Reads the newest 20 invocations by default (`--invocations` widens it), priced first on billed connectors; never reads past the source allowlist.

<Accordion title="Usage and options for dex maintain incidents">

```text
dex maintain incidents [--invocations N] [<object> ...]
```

**Arguments**

| Argument | Description | Default |
| --- | --- | --- |
| `[<object> ...]` | model names: repeated, comma-separated or space-separated (default: all) |  |

**Options**

| Option | Description | Default |
| --- | --- | --- |
| `--invocations N` | read the newest N invocations of Elementary's tables (default 20, at most 2000) |  |

</Accordion>

## dex maintain diagnose

Bisect each open incident over its coverage timeline, bound the break with the committed maintain snapshot series where there is one, and confirm each candidate cause with a check Dex already has. Answers one cause, several, or none, with what was ruled out and the window no recorded state covers; a confirmed cause's repair is handed to transform, never written here.

<Accordion title="Usage and options for dex maintain diagnose">

```text
dex maintain diagnose [--invocations N] [<object> ...]
```

**Arguments**

| Argument | Description | Default |
| --- | --- | --- |
| `[<object> ...]` | model names: repeated, comma-separated or space-separated (default: all) |  |

**Options**

| Option | Description | Default |
| --- | --- | --- |
| `--invocations N` | read the newest N invocations of Elementary's tables (default 20, at most 2000) |  |
