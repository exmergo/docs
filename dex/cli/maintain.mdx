| Command | What it does |
| --- | --- |
| [`dex maintain snapshot`](#dex-maintain-snapshot) | capture the known-good baseline in .dex/snapshot.json |
| [`dex maintain check`](#dex-maintain-check) | sweep every drift axis against the snapshot |
| [`dex maintain schema`](#dex-maintain-schema) | detect added, dropped, retyped or renamed columns |
| [`dex maintain volume`](#dex-maintain-volume) | detect row counts that collapsed, emptied or spiked |
| [`dex maintain grain`](#dex-maintain-grain) | detect lost key uniqueness and changed grain |

| [`dex maintain reconcile`](#dex-maintain-reconcile) | propose the edits that reconcile detected drift |
| [`dex maintain verify`](#dex-maintain-verify) | check the project is correct now, with no baseline |

## dex maintain snapshot

Pin the current map and fingerprint the project layers as the baseline drift is measured against. `--project-only` opens no connection.

<Accordion title="Usage and options for dex maintain snapshot">

```text
dex maintain snapshot [--project-only]
```

**Options**

| Option | Description | Default |
| --- | --- | --- |
| `--project-only` | refingerprint only the project layers; opens no connection |  |

</Accordion>

## dex maintain check

Run every drift axis against the snapshot and rank the findings. The free axes always run; the scanning axes are offered with an estimate.

<Accordion title="Usage and options for dex maintain check">

```text
dex maintain check [<object> ...]
```

**Arguments**

| Argument | Description | Default |
| --- | --- | --- |
| `[<object> ...]` | object to check (default: the whole project) |  |

</Accordion>

## dex maintain reconcile

Store the reconciling edits as a plan of diffs tagged mechanical or advisory. Never applied here; use transform apply. Repo-only.

<Accordion title="Usage and options for dex maintain reconcile">

```text
dex maintain reconcile [{schema,volume,grain,semantic}]
```

**Arguments**

| Argument | Description | Default |
| --- | --- | --- |
| `[{schema,volume,grain,semantic}]` | reconcile only this drift class (default: all) |  |

</Accordion>

## dex maintain verify

Check build status, column contracts, row population, grain and join contracts against the built relations. Mostly free metadata; view row counts and join probes are offered with an estimate.

<Accordion title="Usage and options for dex maintain verify">

```text
dex maintain verify [--target TARGET] [<object> ...]
```

**Arguments**

| Argument | Description | Default |
| --- | --- | --- |
| `[<object> ...]` | model names: repeated, comma-separated or space-separated (default: all) |  |

**Options**

| Option | Description | Default |
| --- | --- | --- |
| `--target TARGET` | dbt dev target to verify against; prod-looking targets are refused |  |

</Accordion>
