## dex transform init

Propose a new dbt project as create diffs, for the connector named by `--connector` or .dex/config.yml. Refuses if a dbt project exists. Free.

<Accordion title="Usage and options for dex transform init">

```text
dex transform init [--layered-schemas] [--in-place] [<name>]
```

**Arguments**

| Argument | Description | Default |
| --- | --- | --- |
| `[<name>]` | name of the dbt project to create |  |

**Options**

| Option | Description | Default |
| --- | --- | --- |
| `--layered-schemas` | build each layer into its own schema |  |
| `--in-place` | scaffold into the current directory instead of &lt;name>/ |  |

</Accordion>

## dex transform plan

Validate the edits in `--edits-file`, diff them against the project, and store a plan. Nothing is written until transform apply. Repo-only.

<Accordion title="Usage and options for dex transform plan">

```text
dex transform plan [--edits-file FILE] [--scaffold TABLE]
    [--attribute-rows | --no-attribute-rows] [<intent>]
```

**Arguments**

| Argument | Description | Default |
| --- | --- | --- |
| `[<intent>]` | one line saying what the edits are for |  |

**Options**

| Option | Description | Default |
| --- | --- | --- |
| `--edits-file FILE` | the edits payload as JSON; '-' reads stdin |  |
| `--scaffold TABLE` | add a staging model skeleton for a profiled table |  |
| `--attribute-rows` | measure the row-population delta of each change |  |
| `--no-attribute-rows` | name row-affecting changes without measuring them |  |

</Accordion>

## dex transform apply

Write a plan's diffs into the project. With no id, applies the latest unapplied plan. A file edited since planning is a conflict, never an overwrite. Repo-only.

<Accordion title="Usage and options for dex transform apply">

```text
dex transform apply [--plan-file FILE] [--expect-digest HEX] [<plan-id>]
```

**Arguments**

| Argument | Description | Default |
| --- | --- | --- |
| `[<plan-id>]` | plan to apply (default: latest unapplied, named in data.resolved_plan) |  |

**Options**

| Option | Description | Default |
| --- | --- | --- |
| `--plan-file FILE` | apply an exported plan document instead of a stored plan |  |
| `--expect-digest HEX` | refuse a plan document whose digest is not this one |  |

</Accordion>

## dex transform build

Run dbt build on a dev target only, after a free preflight and a cost estimate. It runs only with `--confirm` and `--budget`.

<Accordion title="Usage and options for dex transform build">

```text
dex transform build [--target TARGET] [--select SELECTOR] [--verify]
    [--for-plan PLAN-ID] [--for-plan-file FILE] [--no-install-deps]
    [--cold-deps] [--full-refresh]
```

**Options**

| Option | Description | Default |
| --- | --- | --- |
| `--target TARGET` | dbt target to build; prod-looking targets are refused |  |
| `--select SELECTOR` | dbt node selection (one or more selectors, or quoted), passed through to dbt |  |
| `--verify` | run the maintain verify sweep over the built nodes |  |
| `--for-plan PLAN-ID` | report whether the build covered this stored plan |  |
| `--for-plan-file FILE` | report coverage of an exported plan document |  |
| `--no-install-deps` | refuse missing dbt packages instead of installing them |  |
| `--cold-deps` | reinstall packages in an isolated copy and build from it |  |
| `--full-refresh` | rebuild selected incremental models after their logic changed |  |

</Accordion>

## dex transform deps

Run dbt deps inside the project. It installs the packages the project already declares in packages.yml, at the versions package-lock.yml pins where the lockfile matches that file (dbt resolves them again where it does not); it does not install or upgrade a tool. Repo-confined, with no warehouse spend.

<Accordion title="Usage and options for dex transform deps">

```text
dex transform deps
```

</Accordion>

## dex transform references

Report every use of each name across model SQL, YAML, macros, seeds and installed packages, and say how complete the answer is. With `--usage`, also how other models filter, branch on or aggregate each model.column. Repo-only and free.

<Accordion title="Usage and options for dex transform references">

```text

```

**Arguments**

| Argument | Description | Default |
| --- | --- | --- |
| `<name> [<name> ...]` | name to look up; model.column resolves through ref() |  |

**Options**

| Option | Description | Default |
| --- | --- | --- |
| `--kind KIND` | narrow to one kind, such as model, column, var or metric |  |
| `--full` | lift the cap of 200 occurrences across 50 files |  |
| `--usage` | also report how other models use each model.column |  |

</Accordion>

## dex transform declare

<Accordion title="Usage and options for dex transform declare">

    [<model> ...]

## dex transform test

`--scaffold` plans a unit_tests skeleton for a model. `--mutate` plants one defect at a time and reports which ones no test caught; `--downstream` also counts the tests of the models that read it. Mutation runs dbt on the dev target and is billed on metered connectors.

<Accordion title="Usage and options for dex transform test">

```text
dex transform test [--scaffold MODEL | --mutate MODEL] [--max-mutants N]
    [--target TARGET] [--check-equivalence | --no-check-equivalence]
    [--downstream | --no-downstream]
```

**Options**

| Option | Description | Default |
| --- | --- | --- |
| `--scaffold MODEL` | plan a unit test skeleton for this model |  |
| `--mutate MODEL` | measure which planted defects this model's tests miss |  |
| `--max-mutants N` | run at most N mutants (can only lower the cap of 20) |  |
| `--target TARGET` | dbt dev target to mutate against |  |
| `--check-equivalence` | compare each survivor with the model on the dev data |  |
| `--no-check-equivalence` | report survivors without comparing them |  |
| `--downstream` | also run the tests of the models downstream of it |  |
| `--no-downstream` | run only the model's own tests |  |

</Accordion>

## dex transform compare

Compile the model with and without the plan, then compare output columns and the exact row multiset on the same dev inputs. Returns counts, never rows. equivalent holds for the compared inputs only. Scans go through `--confirm` `--budget` on metered connectors.

<Accordion title="Usage and options for dex transform compare">

```text
dex transform compare [--model MODEL] [--map OLD=NEW] [--key COLUMN]
    [--accept-type COLUMN] [--expect JSON | --expect-file PATH]
    [--target TARGET] [<plan_id>]
```

**Arguments**

| Argument | Description | Default |
| --- | --- | --- |
| `[<plan_id>]` | stored plan id (default: latest unapplied, named in data.resolved_plan) |  |

**Options**

| Option | Description | Default |
| --- | --- | --- |
| `--model MODEL` | the model whose results should not change |  |
| `--map OLD=NEW` | a baseline output column the plan renames (repeatable) |  |
| `--key COLUMN` | baseline key column, repeatable; default: declared grain |  |
| `--accept-type COLUMN` | baseline column whose type may change in its family |  |
| `--expect JSON` | JSON: the rows the plan may add, remove and change |  |
| `--expect-file PATH` | read `--expect`'s JSON from a file ("-" reads stdin) |  |
| `--target TARGET` | dbt dev target to read; prod-looking targets are refused |  |

</Accordion>
