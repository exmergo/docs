set up a Dex project, adopt dbt, or explore without dbt

```text
dex init [--mode {new,demo,adopt,explore}] [--project-dir PROJECT_DIR]
    [--target TARGET] [--dev-destination DEV_DESTINATION]
    [--agent-file {AGENTS.md,CLAUDE.md}] [--no-agent-instructions]
    [--no-interactive] [--layered-schemas] [--in-place] [<name>]
```

**Arguments**

| Argument | Description | Default |
| --- | --- | --- |
| `[<name>]` | dbt project name; '.' is in-place; .dex stays at repo root |  |

**Options**

| Option | Description | Default |
| --- | --- | --- |
| `--mode {new,demo,adopt,explore}` | new project, complete demo, adopt dbt, or explore without dbt |  |
| `--project-dir PROJECT_DIR` | existing dbt project to adopt (repository-relative) |  |
| `--target TARGET` | existing dev target to adopt |  |
| `--dev-destination DEV_DESTINATION` | dev namespace: dataset, schema, or database/catalog.schema |  |
| `--agent-file {AGENTS.md,CLAUDE.md}` | agent instruction file to update; repeat to select both |  |
| `--no-agent-instructions` | skip managed agent instructions |  |
| `--no-interactive` | return structured missing inputs without terminal questions |  |
| `--layered-schemas` | build each dbt layer into its own schema |  |
| `--in-place` | scaffold dbt in the current directory |  |

Every command here also accepts the [global options](/dex/cli/overview#global-options).
